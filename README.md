# Coffee Shop Sales Data Analysis
## 1. Project Overview
This project uses Python to analyze coffee shop sales data.
It explores product sales performance, category proportion and monthly sales trends.
The aim is to provide simple business insights for retail and catering operation.

## 2. Data Source
- Dataset: Coffee Shop Sales Dataset
- Source: Kaggle
- Date of access: 2026-04-26
- Main fields: date, product category, transaction amount

## 3. Required Library
pip install pandas matplotlib

## 4. How to Run
1. Download the CSV dataset
2. Put the file in the same folder as the notebook
3. Run all code cells step by step

## 5. Key Findings
1. Hot coffee and bakery products contribute the highest sales.
2. A small number of core categories occupy most revenue.
3. Sales show obvious monthly fluctuation and seasonal features.

## 6. Limitation
The dataset lacks customer information, so user behavior analysis cannot be completed.
