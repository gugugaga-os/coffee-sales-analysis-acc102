# Coffee Shop Sales Data Analysis
## 1. Project Overview
This project uses Python to analyze coffee shop sales data.
It explores product sales performance, category proportion and monthly sales trends.
The aim is to provide simple business insights for retail and catering operation.

## 2. Data Source
- Dataset: Coffee Shop Sales Dataset
- Source: Kaggle
- Date of access: 2026-04-26
- Main fields: date, product category, transaction amount
